# Phase 05 — 실시간 색상/소재 반영 미리보기

## 목표 / 배경

기존 뷰어는 신발 **사진(PNG) 위에 색상 뱃지만** 얹어, 정작 신발 색·소재를 바꿔도
**신발 자체는 안 바뀌었다.** 부위별 색이 **실제로 칠해지는** 미리보기로 바꾼다.
(사진은 부위별 재색칠이 불가 → SVG로 부위를 분리해 `fill` 교체)

## A. 색상 실시간 반영 (1차 — 완료)

- [x] `components/customizer/SvgShoe.tsx` — 측면 스니커즈를 부위별 path로 그리고 `fill`에 `partsConfig` 색 적용 (갑피·밑창·끈·안창·로고)
- [x] `ShoeViewer`를 SVG 기반으로 교체 (PNG 스와이프 뷰 제거, 웹/모바일 프레임폭 480 클램프 유지)
- [x] 색상 변경 → 신발에 **즉시 반영** 확인 가능

## B. 소재 반영 (2차 — 예정)

- [ ] 소재별 시각 차이: 가죽(광택)·스웨이드(무광/노이즈)·메쉬(점 패턴)·캔버스(직조 패턴)
- [ ] SVG `Pattern`/`LinearGradient` 또는 오버레이로 질감 표현
- [ ] 선택 부위 강조(아웃라인) — 어떤 부위를 편집 중인지 시각 표시
