이번 작업 목표: $ARGUMENTS

이 목표를 `phases/phase-0N-<주제>.md` 문서로 작성한다 (N은 기존 `phases/` 폴더의 다음 번호).

## 문서에 포함할 것
- 목표 / 배경
- 체크리스트 (작업 단위로 `- [ ]`)
- 완료 조건
- 다음 phase 포인터

## 진행
- 목표가 한 문장뿐이라 모호하면, 문서를 만들기 전에 한두 가지를 먼저 확인한다.
- 문서를 만든 뒤 그 phase의 체크리스트를 따라 작업을 진행한다.
- 체크리스트 항목을 끝낼 때마다 `npm run verify`(type-check + lint)로 확인한 뒤 `- [x]`로 표시한다.
- 큰 결정이 생기면 `docs/ADR.md`에 ADR 형식으로 기록한다.
- 커밋/배포는 사용자가 허락하기 전에는 하지 않는다.
